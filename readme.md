# Ассистент — Telegram & VK Боты с Dialogflow

Мультиплатформенный чат-бот, использующий Google Dialogflow для обработки естественного языка и интеллектуального ответа на вопросы пользователей. Поддерживает две платформы: Telegram и ВКонтакте.

## Особенности

- Поддержка двух платформ: Telegram и ВКонтакте через единую логику обработки
- Интеграция с Dialogflow: использование мощного NLP для понимания интентов пользователя
- Централизованное обучение: обучение бота через JSON-файл с фразами
- Мониторинг ошибок: отправка уведомлений об ошибках администратору в Telegram
- Простота развертывания: минимальные зависимости и понятная структура проекта

## Структура проекта

```text
├── .env                        # Переменные окружения
├── credentials.json            # Учетные данные Google Cloud
├── requirements.txt            # Зависимости Python
├── settings.py                 # Конфигурация приложения
├── logger.py                   # Настройка логирования с Telegram-уведомлениями
├── bot_tg/
│   ├── tg_bot.py               # Основной скрипт Telegram бота
│   └── tg_handlers.py          # Обработчики сообщений Telegram
├── bot_vk/
│   ├── vk_bot.py               # Основной скрипт VK бота
│   └── vk_handlers.py          # Обработчики сообщений VK
└── dialog_flow/
    ├── phrases.json            # Тренировочные данные для Dialogflow
    └── train_dialogflow.py     # Скрипт обучения Dialogflow
```

## Настройка окружения

1. Клонирование и установка зависимостей

```bash
git clone repository-url

cd project-folder

python -m venv venv

source venv/bin/activate  # Linux/Mac

venv\Scripts\activate     # Windows

pip install -r requirements.txt
```

2. Настройка Google Dialogflow

- Создайте проект в Google Cloud Console
- Включите API Dialogflow
- Создайте сервисный аккаунт и скачайте JSON-ключи
- Переименуйте скачанный файл в `credentials.json` и разместите в корне проекта

3. Создание ботов

Для Telegram:
- Создайте бота через @BotFather
- Получите токен

Для VK:

- Создайте сообщество ВКонтакте
- В настройках сообщества перейдите в "Работа с API"
- Создайте ключ доступа с правами: messages, manage

4. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
# Google Dialogflow
PROJECT_ID=ваш-google-cloud-project-id
GOOGLE_APPLICATION_CREDENTIALS=credentials.json

# Telegram
CONTEXT_ASSISTANT_BOT_TG_TOKEN=ваш-telegram-bot-token
ADMIN_CHAT_ID=ваш-telegram-chat-id # для уведомления об ошибках

# VK
VK_GROUP_TOKEN=ваш-vk-group-token
```

## Запуск проекта

1. Обучение Dialogflow
Перед запуском ботов необходимо обучить Dialogflow интентами:

```bash
python dialog_flow/train_dialogflow.py
```

Скрипт предложит:
- Просмотреть существующие интенты
- Обучить Dialogflow новыми интентами из phrases.json

2. Запуск Telegram бота

```bash
python bot_tg/tg_bot.py
```

3. Запуск VK бота

```bash
python bot_vk/vk_bot.py
```

Примечание: Оба бота можно запускать одновременно в разных терминалах или процессах.

## Обучение бота

**Формат файла `phrases.json`**

```json
{
  "Название интента": {
    "questions": [
      "Вариант вопроса 1",
      "Вариант вопроса 2"
    ],
    "answer": "Ответ бота на эти вопросы"
  }
}
```

**Добавление новых интентов**

1. Отредактируйте dialog_flow/phrases.json
2. Добавьте новые интенты по примеру существующих
3. Запустите скрипт обучения: python dialog_flow/train_dialogflow.py

## Технические детали

**Логирование и мониторинг**

1. Все логи выводятся в консоль с подробной информацией
2. Критические ошибки автоматически отправляются администратору в Telegram

**Диалоговая логика**

1. Для каждого пользователя создается уникальная сессия в Dialogflow
2. Используется язык: русский (language_code="ru")
3. Игнорируются fallback-интенты (когда Dialogflow не распознал намерение)
